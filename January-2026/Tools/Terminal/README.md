# 💻 Terminal

This section belongs to the **Tools** module of the cohort syllabus.

Before working with Git, servers, or backend systems,
you must understand how developers interact with their operating system.

That interaction happens through the Terminal.

---

## 🎯 Why Terminal Matters

The Terminal is not just a black screen with text.

It is:

- A direct interface to your operating system
- The primary way developers interact with Git
- A faster and more powerful alternative to GUI tools
- A foundational skill for backend and DevOps workflows

If Terminal feels uncomfortable,
Git and system-level tools will also feel difficult.

---

- Role of Terminal
- CLI vs GUI
- Navigating directories
- File system structure
- Basic commands
- Creating, deleting, and moving files
- Running programs and scripts
